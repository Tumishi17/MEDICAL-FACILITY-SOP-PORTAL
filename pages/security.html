IT Security Policy

Owner: IT Manager (proposed) · Version: Draft 0.1 · Approval status: Not yet approved

Purpose: Protect the facility's computers, network, central server, research management system and information from unauthorised access, loss or disruption.

Required controls

  • Each user must use an individually assigned account. Do not share passwords.
  • Use strong, unique passwords and multi-factor authentication where supported, especially for privileged and remote access.
  • Grant only the access needed for a person's duties. Approve, review and remove access through a documented process.
  • Keep operating systems and applications updated using an approved maintenance process.
  • Do not disable security software or install unapproved software or remote-access tools.
  • Use the proposed VLAN separation for administration, each laboratory, printers, servers and network management. Restrict unnecessary traffic with approved access controls.
  • Restrict physical access to server rooms, network cabinets and other critical equipment.
  • Protect personal and confidential information; access and share it only for authorised purposes.
  • Use approved removable storage and scan it where suitable security controls are available.
  • Back up critical data and configurations, protect backup copies and test restoration.
  • Report suspicious emails, malware, lost devices, unusual account activity or possible data exposure immediately.
  • Changes to switches, VLANs, routing, server configurations and security controls require authorisation, documentation and appropriate testing.

Incident response

  1. Report the issue promptly through the confirmed service desk or security reporting channel.
  2. Follow authorised instructions to isolate affected devices or accounts.
  3. Preserve relevant evidence; do not casually delete logs or wipe affected devices.
  4. Escalate suspected personal-information exposure to the designated security/privacy contact and management.

Review and enforcement

Employees and contractors must follow this policy. IT staff implement approved controls and document exceptions. Management should review the policy at least annually and after major incidents or material system changes. Any disciplinary action must follow applicable organisational procedures and law.

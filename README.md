# Medical Research Facility – IT SOP Portal

**Project Type:** Website Prototype  
**Domain:** Information Technology / IT Governance  
**Status:** Prototype – Pending Organisational Review and Approval

## 1. Project Overview

The Medical Research Facility IT SOP Portal is a web-based prototype designed to organise and present Information Technology policies, procedures and operational guidelines in one centralised location.

The portal provides a structured interface through which facility personnel can access important IT documentation, including information security, acceptable technology usage, IT acquisition, service desk operations, disaster recovery and document control.

The project demonstrates how a centralised digital portal can improve access to IT documentation and support consistent information management within a medical research environment.

## 2. Project Objectives

- Centralise IT policies and standard operating procedures.
- Improve accessibility and organisation of IT documentation.
- Provide a simple, user-friendly navigation experience.
- Support awareness of IT security and acceptable technology usage.
- Present essential IT operational procedures in a structured format.
- Demonstrate the application of web development in an organisational environment.

## 3. Features and Documentation

The portal includes the following sections:

| Page | Description |
|---|---|
| Home (`index.html`) | Main landing page and navigation interface. |
| IT Security Policy | Security guidelines and information protection. |
| Acceptable Use Policy | Guidelines for responsible use of IT resources. |
| IT Acquisition Procedure | Procedures relating to IT equipment and acquisition. |
| Service Desk Procedure | IT support and incident-handling guidelines. |
| Disaster Recovery Plan | Proposed IT recovery procedures and planning targets. |
| Contacts and Document Control | Contact placeholders and document management information. |

## 4. Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layout and visual presentation.
- **Web Browser** – Accessing and viewing the prototype.

## 6. How to Run the Project

No installation or additional software is required.

1. Download or clone the repository.
2. Extract the project files if downloaded as a ZIP.
3. Open the project folder.
4. Open `index.html` in a desktop web browser.
5. Navigate through the portal using the navigation bar or homepage cards.

## 7. Important Disclaimer

This project is a prototype developed for demonstration and educational purposes. It does not represent an officially approved or operational IT policy portal.

Before operational implementation:

- Replace all contact placeholders with verified organisational details.
- Obtain formal review and approval of all policy and procedure content.
- Confirm document owners, version numbers and effective dates.
- Validate proposed disaster recovery targets with the organisation.
- Test all navigation links and website functionality.
- Ensure that the organisation's requirements and governance standards are met.

The disaster recovery targets included in this prototype are planning suggestions and should not be treated as formally approved recovery commitments.

## 8. Project Limitations

This prototype is a static website built using HTML and CSS. It does not currently include:

- User authentication or role-based access control.
- A database or content management system.
- Automated document version management.
- An administrative dashboard.
- Dynamic document approval workflows.

These features could be considered for future development.

## 9. Future Improvements

Potential enhancements include:

- Implementing a secure authentication system.
- Introducing a centralised database for document management.
- Adding document search and filtering.
- Developing administrative functionality for managing SOPs.
- Implementing document version tracking and approval workflows.
- Improving accessibility and responsive design.

## 10. Project Purpose

This project demonstrates the use of web technologies to develop a structured information portal for managing and presenting IT policies and standard operating procedures within a medical research facility.

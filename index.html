When should I contact IT?

  • When a computer, printer, application or network connection is not working.
  • When access to a system needs to be created, changed or removed.
  • When suspicious emails, malware, lost devices or possible data exposure are noticed.
  • When a purchase or network change needs technical review.

Use the organisation's confirmed support channel. Contact information has intentionally not been invented for this prototype.

Using this portal

Read the relevant SOP before performing a task. Only authorised personnel may approve purchases, change network configurations or restore systems. If a procedure conflicts with an approved organisational policy or an emergency instruction, follow the authorised instruction and report the conflict for review.
